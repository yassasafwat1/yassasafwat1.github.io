About

Detail-obsessed, quality-driven, built for breaking things on purpose.

I'm a Junior Software Tester and QA Engineer who treats every feature as a hypothesis that hasn't failed yet. I plan test cases before I write a single line of automation, and I don't consider something "done" until I've tried to break it from every angle a real user — or a careless one — would.

My work spans manual testing for deep, exploratory coverage, automation testing to keep regressions from ever shipping twice, and API testing to make sure the systems underneath the interface hold up under pressure. I care about clear bug reports, fast feedback loops, and shipping software people can actually trust.

01Manual Testing
Test case design, exploratory testing, regression cycles, and clear, reproducible bug reports.
02Automation Testing
Building and maintaining automated test suites that catch regressions early and run reliably in CI.
03API Testing
Validating endpoints, payloads, and edge cases to confirm the system behaves correctly beyond the UI.
